# Computer Networks Management

A repository dedicated to **Computer Network Management**, **Infrastructure Monitoring**, and **Network Simulation**.<br>
This project centralizes monitoring dashboards, lab topologies, and infrastructure resources used for learning,<br> 
testing, and managing enterprise network environments.

Whether you're studying network administration, building monitoring solutions, or creating virtual labs,<br>
this repository aims to provide practical examples and reusable resources.

---

## Technologies
This repository is based on the following technologies:
* Linux - Windows 
* PNETLab - Prometheus - Grafana - Zabbix

--- 

## Project Goals
The purpose of this repository is to:
* Share monitoring dashboards
* Provide reusable Zabbix configurations
* Support studies and practical learning
